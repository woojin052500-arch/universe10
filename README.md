## 기획 배경

입시 위주의 교육 환경 속에서 10대 청소년들은 교과서 속 지식에 갇혀 넓은 세상을 경험할 기회가 부족합니다.

영하 20도의 산꼭대기에서 120kg의 장비를 이끌고 밤하늘을 기록하는 10대 천문학자의 사례처럼, 세상을 바라보는 **시각과 지식의 크기가 곧 개인의 세계관을 결정**합니다.

> 옆집 소식을 알면 나의 우주는 5미터,<br>
> 태양계의 운동을 알면 1AU,<br>
> 우주의 끝을 알면 1광년.<br>
> **내가 아는 만큼이 곧 나의 우주입니다.**
>
> — 곽준성 (대한천문회 회장)

## 핵심 기능

### 우주 확장 시스템

유저는 퀴즈를 풀며 자신의 **우주 스케일**을 단계별로 확장합니다. 도달한 가장 먼 천체의 거리가 곧 그 사람의 우주 크기가 됩니다.

| 레벨 | 이름 | 스케일 | 천체 수 | 해금 조건 |
|:---:|---|---|:---:|---|
| **Lv.1** | 태양계 | 1 AU | 5 | 처음부터 열림 |
| **Lv.2** | 딥스카이 | 수천 광년 | 17 | Lv.1에서 3개 완료 |
| **Lv.3** | 심우주 | 수백만 광년 | 8 | Lv.2에서 6개 완료 |

천체 **30개**. 가장 먼 곳은 퀘이사(24억 광년)입니다.

### 화면 플로우

```
랜딩 → 우주 지도(동심원) → 천체 상세 → 확장 퀴즈 → 레벨업 줌아웃 연출 ↺
                ↕
          도감 · 관측 칼럼 · MY
```

- **우주 지도** — 레벨이 동심원으로 표현되고, 중심의 흰 점이 '나'. 잠긴 레벨은 점선 처리
- **천체 상세** — 곽준성 회장이 촬영한 원본 사진 + 관측 일지
- **확장 퀴즈** — 3지선다. 선택 즉시 채점, 오답이면 정답도 함께 하이라이트
- **레벨업 연출** — 동심원이 화면 밖으로 확장되며 스케일 숫자가 바뀌는 줌아웃 애니메이션. **서비스 정체성**
- **탐색** — ★ 실제 좌표 기반 딥줌 우주 지도. 아래 별도 설명
- **관측 칼럼** — 곽준성 회장의 관측기. 읽기 폭 720px 고정
- **MY** — 내 우주 스케일, 레벨별 진행률, 로그인/로그아웃

### 로그인과 진도 저장

| 상태 | 동작 |
|---|---|
| Supabase 미설정 | localStorage에만 저장 (앱은 정상 동작) |
| 설정 + 비로그인 | localStorage |
| 설정 + 로그인 | Supabase에 저장. **로그인 순간 로컬 진도를 서버로 자동 병합** |

`.env.example`을 복사해 `.env.local`을 만들고 값을 채우면 로그인이 켜집니다.
필요한 SQL은 [`src/lib/supabase.js`](src/lib/supabase.js) 주석에 있습니다.

## 배포

**Vercel** 로 배포합니다. `main` 브랜치에 푸시하면 자동으로 재배포됩니다.

최초 연결:

1. [vercel.com](https://vercel.com) → GitHub 로그인
2. **Add New → Project** → `universe10` Import
3. 설정 변경 없이 **Deploy** (Next.js 자동 인식)

진도는 브라우저 localStorage에 저장되므로 별도 환경변수는 없습니다.
Supabase 연동 시 `NEXT_PUBLIC_SUPABASE_URL` / `NEXT_PUBLIC_SUPABASE_ANON_KEY` 를
Vercel 프로젝트 설정에 추가하세요.

## 탐색 지도 (`/collection`)

한 화면에 다 담지 않고, **직접 끌고 확대하며 자기 우주를 넓혀가는** 화면입니다.

### 좌표계

| 축 | 값 | 의미 |
|---|---|---|
| **반지름** | log₁₀(거리) | 바깥으로 갈수록 먼 우주. **줌아웃 = 내 우주가 넓어짐** |
| **각도** | 적경(RA) + 적위 보정 | 같은 방향의 천체가 같은 쪽에 모임 |
| **크기** | 실제 겉보기 지름(분각) | 안드로메다가 보름달보다 큽니다 |

- 반지름(거리)은 **정확히** 유지합니다. 겹치는 천체만 각도를 미세 조정합니다.
- 겉보기 크기는 그대로 쓰면 행성이 1px도 안 되므로 제곱근으로 압축했습니다.
  **팝업에는 진짜 겉보기 크기를 표시**합니다 (예: 토성 18″, 안드로메다 3.2°).
- 태양계 천체는 하늘에서 움직이므로 대표 위치를 씁니다. 팝업에 명시됩니다.

### 조작

- **드래그** 이동 · **휠/핀치** 확대 (0.16× ~ 260×) · 하단 이름으로 영역 점프
- 화면상 지름이 26px을 넘으면 점이 **사진으로 피어납니다**
- 천체를 누르면 팝업 → 거리·겉보기 크기·적경/적위·관측 일지 → **퀴즈 풀고 영역 넓히기**

### 화면

안내선·격자·경계원 같은 UI 장치를 두지 않았습니다. 검은 하늘에 천체만 떠 있습니다.

- 배경 별 **1,100개** — 실제 별색 분포(흰·푸른·노란·주황)와 밝기 분포를 따릅니다.
  월드에 박혀 있어 이동·확대에 함께 반응합니다.
- 화면 고정 미세 별 레이어가 하나 더 있어 **시차(parallax)** 로 깊이가 생깁니다.

### 렌더링 방식

월드 전체를 CSS `transform: scale()` 하지 않고, **천체마다 화면 좌표를 직접 계산**합니다.

```
화면 좌표 = 월드 좌표 × 배율 + 이동
```

- 크게 확대해도 거대한 합성 레이어가 생기지 않습니다.
  (예전 방식은 확대 시 브라우저 텍스처 한계를 넘겨 화면이 통째로 사라졌습니다)
- 화면 밖 천체는 아예 그리지 않아 **확대할수록 오히려 가벼워집니다**.
- 이미지 크기는 6000px에서 잘라 한계를 넘지 않게 했습니다.
- 배경 별은 `<canvas>` 에 화면 크기만큼만 그립니다.
- 천체 사진은 가장자리를 마스크로 날려 하늘에 자연스럽게 얹힙니다.
- 화면 가장자리에 약한 비네팅 — 접안렌즈를 들여다보는 느낌.
- 진도는 밝기로 표현합니다. 수집한 천체는 선명하고, 아직 안 푼 것은 어둡습니다.

## 콘텐츠 관리

모든 천체 데이터는 **`src/data/content.js` 한 파일**에 있습니다.

```js
{
  id: 'm42',
  level: 2,
  nameKo: '오리온 대성운',
  catalog: 'M42',
  scaleLabel: '1,344 광년',
  ly: 1344,                                  // 우주 스케일 계산용
  image: { status: 'ready', slug: 'm42' },   // public/objects/m42.jpg
  log: '오리온 대성운은 새로운 별들이...',
  quiz: { q: '...', options: [...], answer: 0, explain: '...' },
  isTemp: false,                             // true면 화면에 '임시' 뱃지
}
```

### 임시 콘텐츠

`isTemp: true`인 항목 **14개**는 감수 전 임시 텍스트입니다. 화면에 `임시` 뱃지가 붙습니다.
관측 칼럼 3편도 모두 임시 원고입니다 (`src/data/columns.js`).

감수 후 텍스트를 교체하고 `isTemp: false`로 바꿔주세요.

### 사진

`public/objects/{slug}.jpg` 로 넣으면 자동으로 붙습니다. **파일이 없으면 앱이 깨지지 않고 기본화면(실루엣)으로 대체**됩니다.

현재 없는 사진 8개: 태양 · 오리온자리 · 백조자리 · M1 · M57 · 중성자별 · 블랙홀 · 퀘이사

자세한 목록은 [`public/README.txt`](public/README.txt) 참고.

## 디자인 시스템

배경 사진(말머리성운)의 발광색에서 팔레트를 추출했습니다.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--ink` | `#05070E` | 배경 |
| `--lv1` | `#E8D9C0` | Lv.1 태양계 |
| `--lv2` | `#7FA8FF` | Lv.2 딥스카이 |
| `--lv3` | `#E8737F` | Lv.3 심우주 |
| `--text` | `#DCE1EA` | 본문 (**순백 금지** — 다크 배경에서 눈부심) |
| `--muted` | `#98A0B2` | 보조 텍스트 |

### 스크림 규칙

천체 사진 위에 흰 텍스트를 그냥 올리면 읽히지 않습니다. 화면별로 오버레이 강도를 다르게 적용합니다.

| 화면 | variant | 강도 | 블러 |
|---|---|---|---|
| 랜딩 | `hero` | 그라디언트 (하단 .99) | — |
| 우주 지도 | `map` | 0.89 | 14px |
| 퀴즈 · 마이 | `max` | 0.95 | 20px |

데스크톱(900px↑)에서는 랜딩 스크림이 **세로 → 가로 방향**으로 바뀝니다.
